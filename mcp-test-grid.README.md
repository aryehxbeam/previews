# MCP Prompt Generator (`mcp-test-grid.html`)

A single-file, client-side tool for generating and curating test prompts for the
Crossbeam MCP agent. Live at
<https://aryehxbeam.github.io/previews/mcp-test-grid.html>.

## What it's for

The MCP agent routes natural-language questions to tools. To test routing and
tool behavior we need realistic prompts. This page holds a curated set of
**intents**, each with a canonical phrasing plus messy real-world variants, and
lets you roll them with your own partner/account/tag values filled in.

It pairs with the Notion checklist "MCP Agent - Smoke + Variant Checklist",
which records what each prompt *should* trigger and the results of running them.

## Where the content comes from

- **Intents** were distilled from ~444 real user questions captured off the
  Agent Analytics Dashboard, grouped into intent categories.
- Each intent is tagged with `useCases` = stable `crossbeam_mcp.tooling.ToolUseCase`
  identifiers (survive tool renames), so it stays valid as tools are renamed or
  consolidated.
- The "real captures" expandable on each card shows the raw questions that
  seeded that intent (these still reference the older staging tool names).

## How it's structured (all inline in the HTML)

- `INTENTS` - the data: `{ name, sourceCategory, description, templates[], variants{}, useCases[] }`.
  - `templates` = clean canonical phrasings.
  - `variants` = real-world distortions, keyed by type: `casual`, `followup`,
    `multi`, `filtered`, `typo`, `lang_fr`, etc.
- `SAMPLE_PARTNERS` / `SAMPLE_ACCOUNTS` / `SAMPLE_TAGS` - default seed values
  (currently the dev sandbox org's real partners/accounts/tags).
- Placeholders like `{partner}`, `{account}`, `{tag}`, `{partner_typo}` are
  filled at "roll" time from the sidebar lists (or the samples if empty).
  `{partner_typo}` is generated by `mangle()`, which injects 1-2 realistic typos.

## Sidebar + persistence

Paste your own partners / accounts / tags in the sidebar to fill placeholders
with your data. Entries persist per-browser in `localStorage`
(`mcp_test_grid_partners_v3`, `_accounts_v2`, `_tags`). Bump the version suffix
in the source when you change the default seeds so returning visitors re-seed.

## Filters

Filter by use-case, source category, or variant type. **When a variant-type
filter is active, each card collapses to only its matching variant prompts**
(canonical templates and other variants are hidden), and "Roll all" / "Copy
filled list" scope to just those - so you can pull, e.g., every `typo` prompt.

## Updating / republishing

The source of truth is edited locally, then published to this repo (GitHub
Pages serves it):

```
# edit the html, then:
cp mcp_test_grid.html <clone-of-previews>/mcp-test-grid.html
cd <clone-of-previews> && git add mcp-test-grid.html && git commit -m "..." && git push
```

GitHub Pages rebuilds within a minute or two. If the latest commit isn't
serving, check `gh api repos/aryehxbeam/previews/pages/builds` for an `errored`
latest build and re-push to trigger a fresh one.
