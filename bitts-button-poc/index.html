BittsButton

A static HTML + Tailwind reproduction of the real packages/bitts/src/BittsButton component. Two independent axes: type (color family) and variant (fill style), plus size, and states. The backing CSS is the component's own scoped rules, driven by the repo's design tokens - no brand hex in the markup. Hover, press, and keyboard-focus (Tab) states are live - interact with any button below.

type

primary, neutral, danger, white, upsell

variant

fill, outline, ghost

size

large, medium, small, x-small

Generated from Figma (Bitts - Atoms - Molecules, node 647:0) reconciled against the component source.
